description: Implement a feature using a controlled development process
---

Implement the feature I describe.

Before making changes:

1. Read the applicable project rules.
2. Read the relevant skills and documentation.
3. Inspect the existing implementation.
4. Confirm the requirements and acceptance criteria.
5. Create an implementation plan.

If the plan has not already been approved, present it and wait.

After approval:

1. Implement the feature using existing conventions.
2. Modify only the necessary files.
3. Reuse existing components and services where appropriate.
4. Handle loading states, errors, validation, and edge cases.
5. Add or update relevant tests.
6. Run the appropriate tests and checks.
7. Review the final diff for bugs, regressions, and security issues.

Do not deploy, delete files, or introduce dependencies without approval.

At the end, summarize the implementation, changed files,
test results, and any remaining issues.
