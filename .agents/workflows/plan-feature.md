description: Understand a task and produce an implementation plan without modifying code
---

Help me plan the requested feature.

Follow these steps:

1. Read the applicable project rules.
2. Inspect the project structure and relevant documentation.
3. Understand the existing implementation.
4. Identify the files and components involved.
5. Trace the relevant data flow and dependencies.
6. Identify edge cases, security concerns, and possible regressions.
7. Propose a step-by-step implementation plan.
8. List the files that would need to change.
9. Describe how the implementation will be tested.

Do not create, edit, or delete any files.

Present the plan and wait for my approval.
Do not begin implementation until I approve it.
